# 🎉 agente-admin-observabilidad - Streamline Your Alert Analysis

## 🚀 Getting Started
Welcome to agente-admin-observabilidad! This application helps you analyze alerts automatically using the Agno Framework and the Grafana Stack. It includes different agents for monitoring and quick commands to ensure seamless observability.

## 🔍 Features
- **Agno Framework Integration**: Enjoy solid support for alerts and observability.
- **Multi-Agent System**: Utilize WatchdogAgent, TriageAgent, and ReportAgent for comprehensive monitoring.
- **Real-Time Commands**: Access quick commands for immediate observability adjustments.
- **Grafana Stack**: Leverage Grafana for data visualization to track your performance.

## 🖥 System Requirements
To ensure that the application runs smoothly, you should have the following on your computer:

- Minimum 4GB RAM
